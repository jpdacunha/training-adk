# SEO Checklist

Use this skill to evaluate or improve blog content for search performance.

## Review criteria

1. Title: 50-60 characters, primary keyword near the start.
2. Meta description: 150-160 characters, includes a call to action.
3. Headings: use a logical H2/H3 hierarchy with keywords in a few headings.
4. First paragraph: include the primary keyword in the first 100 words.
5. Keyword density: keep it natural; avoid forced placement.
6. Paragraphs: keep most paragraphs to 2-3 sentences; prefer bullet lists for readability.
7. Links: include a few relevant internal and external links.
8. Images: use descriptive alt text and compressed, optimized files.
9. URL slug: short, relevant, hyphenated, and keyword-rich.

## Review workflow

- Check each criterion one by one.
- Call out strengths and gaps.
- Suggest specific editorial improvements.
- Prioritize changes that improve readability and relevance before purely technical fixes.

## Output style

Provide a concise audit with:

- a pass/fail summary per section
- recommended title or metadata revisions
- a short list of text-level changes to improve SEO without harming quality
